As a rider of the system, I want to see all the fares for each rider category with the fare for each

- show me all fares by grouped by rider category

mysql> SELECT
       fareCategory,
       MAX(CASE WHEN riderCategory = 'regular' THEN price END) AS regularFare,
       MAX(CASE WHEN riderCategory = 'reduced' THEN price END) AS reducedFare,
       MAX(CASE WHEN riderCategory = 'student' THEN price END) AS studentFare
     FROM Fare
     GROUP BY fareCategory
     ORDER BY fareCategory;
